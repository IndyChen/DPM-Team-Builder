# 🌊 鳴潮終焉矩陣編隊工具 (DPM Team Builder v4.9.4)

> **當前工具版本**：`v4.9.4` ｜ **基準客戶端版本**：`v3.8.12`

這是一款專為《鳴潮》(Wuthering Waves)「終焉矩陣」模式設計的純前端網頁版配隊與實戰推演工具。  
依據遊戲客戶端 `v3.8.12` 規則與社群招式數據庫，結合**招式時間軸 Buff 清算**、**共鳴鏈與裝備面板縮放**、**轉場空白推演**與**互動式視覺化戰報**，協助玩家依據個人角色池與實戰排軸手法，規劃高還原度的出戰陣容與實戰分數預估。

---

## ✨ 核心功能特色 (v4.9.4)

### 1. 🎒 共鳴者名冊與多槽位裝備面板
- 勾選持有共鳴者後即可隱藏不可用陣容，支援拖曳編隊、生存位耐力上限（1～3 次）與**漂泊者屬性互斥**。
- 可為每位角色建立**多套配置槽位**，細部調整共鳴鏈（S0～S6）、武器、聲骸套裝／首位聲骸與雙暴面板；亦支援「➕ 新增角色」建立自訂共鳴者。

### 2. ⚔️ 排軸管理器、招式庫與 Buff 時機調節
- 支援**純文字、分享碼匯入**，以及透過官方招式庫與**鍵位排軸編輯器**組裝「啟動軸」、「主循環軸」與「轉火折損軸」（🟩輕鬆 / 🔵中等 / ⭐進階 / ⚠️極難 / 🧩特化）。
- 自動比對多語系招式名稱並識別**固定暴擊率節點**，依「角色面板 − 排軸基準」暴擊率差值計算浮動區間。
- 編輯排軸時可針對各角色獨立調節**延奏、大招／領域與護盾 Buff 觸發秒數**（留空則依招式節點自動判定），並即時連動傷害與時間軸。

### 3. 🧠 終焉矩陣 3.8／3.7 實戰推演與 Buff 時間軸引擎
- **分隊中位數銜接與自動啟動軸**：隊伍之間以中位數戰果銜接下一波，並自動套用已編寫之啟動軸。
- **角色標籤限定矩陣增益**：支援 3.8／3.7 期矩陣規則自動擇優或單隊指定重排。
- **保守 Buff 時間軸帳本**：依真實出招時序追蹤隊友延奏（14s 單體／15s／30s 全隊）、領域／大招窗與嚴格 2 秒護盾窗，並內建：
  - **矩陣起手 0 協奏閘門**：開局協奏能量為 0，僅在累積滿協奏或觸發「同奏」後才可觸發變奏與延奏技能。
  - **脫戰 ≥ 4 秒開局預觸發**：如特定進戰或非戰備層機制於 0 秒生效。
- **轉場空白時間清算（非等比壓縮）**：循環中途斬殺首領時，於斬殺點後插入實際轉場空白並平移後續節點，依真實流逝時間結算剩餘 Buff、目標負面重置（跨波繼承與自身資源除外）及連鎖轉火折損。
- **精細異常效應與波次機制**：支援六大異常效應層數消耗／時間衰減／上限累加、W4 辛吉勒姆【迷航】不同名聲骸去重計數，以及角色專屬資源跨波策略（如緋雪【鍛雪·歸刃】點數拆分精算）。

### 4. 📊 互動式戰報與 Buff 狀態時間軸圖表
- **精簡沙盤卡片與一鍵跳轉**：沙盤單行直接呈現槽位徽章、適用矩陣增益、實效 DPS 與 **保底／中位／極限** 三段分數，點擊 `查看戰報 ↘` 即可定位詳細戰報。
- **階段切換與複讀輪次**：完整呈現 `啟動軸 ➔ 進入循環軸 ➔ 循環軸 #2 ➔ ...` 與轉火接駁流程。
- **甘特泳道圖表 & 文字帳本**：可切換「全程實戰」、「啟動軸」、「循環軸」與「轉火縫合」檢視每招傷害佔比、當下生效隊友 Buff 剩餘秒數、嚴格 2 秒護盾窗與 Buff 機／BOSS DEBUFF 層數，並支援一鍵複製完整文字帳本。
- **雙軌戰況圖表與實戰逆算**：繪製極限／保底雙軌得分曲線；輸入實戰分數即可反推真實輸出，誤差超過 15% 自動提示。

### 5. 💾 本機存檔、多語系與匯出分享
- 所有名冊、配置、自訂排軸與環境設定皆自動儲存於瀏覽器 `LocalStorage`，可透過右上角「⚙️ 數據總管與備份」匯出備份碼、還原或無損升級舊版資料。
- 內建**繁體中文／簡體中文／日文／英文**四語切換、⚡霓虹／🌿護眼雙主題與一鍵匯出實戰排班圖。

## 🛠️ 技術架構與本地執行

本專案採用純前端架構（無須後端伺服器，所有運算皆於瀏覽器端執行）：
- **核心框架**：Vue 3 (`^3.5.30`) + Vite (`^8.0.1`)
- **樣式與工具**：Tailwind CSS v4 (`@tailwindcss/vite`)、`vue-i18n`、`lz-string`、`html-to-image`

於 `4.9.4` 目錄下執行：

```bash
npm install
npm run dev      # 啟動本地開發伺服器
npm run build    # 建置 dist 靜態發佈檔
npm run preview  # 預覽建置結果
```
